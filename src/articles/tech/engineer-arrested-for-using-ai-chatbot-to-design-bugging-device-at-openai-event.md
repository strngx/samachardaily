A federal arrest last week targeted an engineer accused of using an AI chatbot to design a covert audio‑recording system for an OpenAI conference room in San Francisco.

Prosecutors say the engineer submitted prompts that instructed the chatbot to build a continuous recorder, enable speech‑triggered activation, add Wi‑Fi connectivity and encrypt the memory‑card data.

The alleged scheme underscores law‑enforcement focus on AI‑assisted espionage tools and raises security concerns for technology events.
