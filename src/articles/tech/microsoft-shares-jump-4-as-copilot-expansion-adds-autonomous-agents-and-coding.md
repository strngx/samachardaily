Shares of Microsoft Corporation rose approximately 4% during Friday's trading session following the company's release of a significant feature upgrade to its Copilot artificial intelligence assistant. The update introduces advanced software development tools, including coding capabilities, designed to enhance technical workflows alongside broader system integrations.

Beyond programming support, the latest Copilot rollout incorporates autonomous AI agents and grants the assistant direct operational access to Microsoft Office applications. These enhancements align with the software manufacturer's strategy to transform Copilot from a standalone assistant into an integrated enterprise productivity platform that unifies core workplace software.
