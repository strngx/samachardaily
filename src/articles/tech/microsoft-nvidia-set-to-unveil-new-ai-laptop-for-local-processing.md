Microsoft and NVIDIA are set to unveil a new AI-focused laptop, expected to be called the Surface Laptop Ultra, at a San Francisco event on Wednesday. CEOs Satya Nadella and Jensen Huang are expected to present.

The device aims to run AI agents locally, reducing reliance on Azure cloud data centers and letting code be written without cloud dependency. NVIDIA's RTX Spark chips are central to the effort, which also positions NVIDIA to compete with Intel and AMD.

Analysts warn rising memory costs could limit affordability. NVIDIA recently raised its DGX Spark price about 75% to $6,950. Moor Insights & Strategy's Anshel Sag noted hardware is now too expensive to run local AI for most users.
