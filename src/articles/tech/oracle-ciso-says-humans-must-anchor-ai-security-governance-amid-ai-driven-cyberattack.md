Oracle’s CISO warned that enterprises facing AI‑driven cyberattacks need AI security governance capable of controlling autonomous systems that can access data, link applications and act on users’ behalf.

He said human accountability must become a core security requirement, supplementing traditional controls, and that security teams must map data flows and the processes created by AI agents.

The guidance calls for creating a dedicated human role to oversee these agents, ensuring oversight as AI capabilities expand.
