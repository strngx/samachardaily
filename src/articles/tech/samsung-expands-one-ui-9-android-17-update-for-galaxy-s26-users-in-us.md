Samsung has broadened the distribution of its Android 17-based One UI 9 update to Galaxy S26 users across the United States. The latest software build delivers fresh Galaxy AI functionality alongside strengthened privacy controls and additional features for Samsung Health.

System enhancements extend across multiple built-in utilities, offering expanded customization options for the Quick Panel layout and new control capabilities for Bixby. Accessibility tools have also been refined within the user interface.

Furthermore, the software upgrade brings new multitasking capabilities to Samsung DeX, giving users enhanced productivity features when connected to external display environments.
