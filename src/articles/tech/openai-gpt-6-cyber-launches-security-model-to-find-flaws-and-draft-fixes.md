OpenAI debuted its latest cybersecurity model on November 5, 2026. It does not compose poetry or manage inboxes. The system scans code for weaknesses, produces working exploits, and creates patches.

The model rests on GPT-6 Astra and was adjusted for offensive security. OpenAI gave it a Critical cybersecurity rating, rising from High on GPT-5.6 Cyber.

Before its release was revealed, it identified 81 previously unknown Firefox flaws and built working exploits for 948 Linux kernel vulnerabilities. OpenAI says entry is restricted to vetted security professionals in the Daybreak Red program.
