Microsoft is reportedly developing a capability that would let Android phones serve as secondary displays for Windows PCs, based on code observed in the Link to Windows app.

The addition would mirror Apple’s Sidecar feature, which lets macOS extend onto an iPad, filling a gap in the Link to Windows app’s functionality that has lacked phone‑as‑display support.

A note in the source indicates the feature may be limited to paid plans if it reaches release.
