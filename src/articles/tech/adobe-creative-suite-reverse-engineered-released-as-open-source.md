According to the report, a small group of two to four 'Vibecoders' from the company Aircraft fed the binary machine code of Adobe's Creative Suite into Anthropic's Claude AI model Opus 5.5. The AI generated a functional source code version of the entire suite, which the team then released as open source.

The release includes all products in the suite, though the team acknowledges that numerous bugs remain. They stated that they expect to resolve all bugs within one month. The implications are described as huge for the software industry.
