OpenAI rolled out an official ChatGPT add‑in for Microsoft Word on September 17, 2026, embedding generative artificial intelligence directly into the Word desktop and web environments through a persistent interactive sidebar.

The integration enables users to draft new content, summarize lengthy sections, rewrite existing text, adjust tone, and format complex business documents without switching between external browser tabs. Writers can prompt the add‑in to generate executive summaries, project proposals, and meeting memos, or request targeted structural revisions on specific highlighted paragraphs and numbered lists.

The add‑in is available to users across all ChatGPT subscription tiers, including free accounts, via installation from the Microsoft Marketplace. For enterprise environments, the deployment incorporates organizational controls: administrators can manage permissions through the ChatGPT workspace console, while Microsoft 365 tenant administrators must authorize access before rollout. Default tenant enablement is scheduled to take effect on October 1, 2026.

While the tool accelerates routine drafting and language refinement, the platform documentation notes that complex multi-column layouts, quantitative data tables, and specialized formatting continue to require manual review. The feature reflects an ongoing push to integrate generative AI tools into primary workplace software suites.
